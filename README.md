# حسابداری شخصی Liho

نسخهٔ فارسی موبایل با طراحی شیشه‌ای الهام‌گرفته از آرا.

## حساب‌ها
- در نصب تازه هیچ حسابی از پیش ساخته نمی‌شود.
- از دکمهٔ «＋ افزودن حساب» حساب دلخواه بسازید؛ نوع حساب، نام بانک، چهار رقم آخر کارت و موجودی اولیه اختیاری/قابل تنظیم‌اند.
- شمارهٔ کامل کارت را وارد نکنید.

## تاریخ و مبلغ
- نمایش تاریخ‌ها و انتخاب تاریخ در بخش‌های برنامه بر پایهٔ تقویم شمسی است.
- مبالغ هنگام تایپ و در نمایش‌ها با رقم فارسی و جداکنندهٔ هزارگان قالب‌بندی می‌شوند.

## ثبت پیامک
متن پیامک را خودتان کپی و در صفحهٔ ثبت پیامک بچسبانید؛ مبلغ تشخیص داده می‌شود و بعد دسته و حساب را انتخاب می‌کنید. وب‌اپ آیفون نمی‌تواند خودکار پیامک‌ها را بخواند.

## انتشار به‌روزرسانی
برای به‌روزرسانی نسخهٔ فعلی سایت، `index.html` را در ریشهٔ مخزن GitHub جایگزین و Commit کنید. فایل‌های `manifest.webmanifest` و `liho-icon.png` که قبلاً در مخزن گذاشته شده‌اند، همان فایل‌های لازم برای نصب و آیکون هستند.
